# ドロップレット検索サイト（追加機能版）

1406枚のドロップレット画像を検索できる静的サイトです。

## 追加した機能

### 2. よく使うタグ
- 検索窓の下に、よく使いそうなタグをチップ表示
- タップ / クリックすると検索欄に追加されます

### 3. 複数選択して一括ダウンロード
- 各画像に「選択」ボタンを追加
- 選択した画像は上部バーから一括ダウンロードできます
- 「表示中を全部選択」もできます

### 4. お気に入り機能
- 各画像に「お気に入り」ボタンを追加
- お気に入りはブラウザの `localStorage` に保存されます
- 「お気に入りだけ表示」もできます

## そのほか
- 画像の個別コピー / 個別ダウンロードも継続
- プレビュー画面からもお気に入り・選択・コピー・保存が可能
- GitHub Pages にそのまま置いて使えます

## 注意
- 一括ダウンロードは、ブラウザ上で複数ダウンロードを順番に開始する方式です
- ブラウザによっては「複数ファイルのダウンロードを許可しますか？」と聞かれる場合があります
